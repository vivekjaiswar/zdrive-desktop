Updated 2026-10-04. Covers everything merged into main, including retry resilience, pin-to-keep-local (new section 8), local event logging, and the Windows installer elevation fix. Check boxes as you go — this page doesn't save state, so take a screenshot or note results elsewhere when done.

Report back, for each platform: which steps passed, which failed (with the exact error/behavior you saw), and anything that felt slow or wrong even if it "worked."

0. Setup Windows + Mac

Known fix, PR #6: if your build predates this merge, the installer requests admin elevation for the whole install, which also elevates the finish page's sign-in step — Chrome (and most browsers) silently refuses to open when launched elevated, so sign-in looks like it does nothing. Once PR #6 is merged and you're on a build built after it, the installer no longer requests elevation up front; only the WinFsp driver step (if needed) shows its own separate UAC prompt.

Windows Windows

zdrive-windows-amd64.exe login --url https://staging.zhdrive.in/api
zdrive-windows-amd64.exe mount zdrive: Z: --vfs-cache-mode full

macOS Mac

xattr -d com.apple.quarantine ./zdrive-macos-arm64   # Intel: zdrive-macos-amd64
chmod +x ./zdrive-macos-arm64
./zdrive-macos-arm64 login --url https://staging.zhdrive.in/api
mkdir -p ~/ZDrive
./zdrive-macos-arm64 nfsmount zdrive: ~/ZDrive --vfs-cache-mode full
